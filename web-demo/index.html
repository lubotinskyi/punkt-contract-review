Учебная веб-версия

Автономная проверка без LLM

Работает прямо в браузере. Документы и история сохраняются на этом устройстве и не загружаются в общую базу сайта.

Интеграция OAuth ChatGPT оставлена в локальном приложении и ещё не проверена на реальном аккаунте. Вход на сайт не подключает модель.

Для переноса результатов скачайте JSON или DOCX. При очистке данных браузера история удалится.
