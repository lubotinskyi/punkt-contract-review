# Пункт — проверка договоров поставки

Учебный проект: проверка проекта договора по типовой форме, положению о закупках, спецификации и справочнику поставщиков. Юрист видит цитаты, редактирует замечания, принимает или отклоняет их и подтверждает версию протокола перед экспортом.

**Репозиторий подготовлен для передачи разработки коллеге. Начните с [HANDOFF.md](HANDOFF.md).**

## Две версии приложения

| Папка | Назначение | Хранение | Подключение модели |
|---|---|---|---|
| `local-app/` | Основное Python-приложение: FastAPI, SQLite, python-docx, локальный поиск | Локальная SQLite | OAuth ChatGPT реализован; реальный вход и генерация ещё не проверены |
| `web-demo/` | Опубликованная учебная версия для ChatGPT Sites, HTML/CSS/JavaScript | IndexedDB браузера | LLM и OAuth отсутствуют |

Сайт: https://punkt-contract-review.anikaazimova.chatgpt.site

На сайте работают формализованные проверки и весь путь юриста до DOCX/JSON. Это самостоятельная демонстрационная реализация, а не размещённый Python-сервер. История между устройствами не синхронизируется. Очистка данных браузера удаляет её.

## Запуск основной версии на Windows

Нужен Python 3.12.

```powershell
git clone https://github.com/lubotinskyi/punkt-contract-review.git
cd punkt-contract-review\local-app
.\start.bat
```

Откройте http://127.0.0.1:8000. Нажмите «Загрузить учебный пример», затем «Начать проверку». Демонстрация не требует ключей и вызовов модели. При первом запуске зависимости скачиваются из интернета.

Если окружение уже установлено:

```powershell
.\.venv\Scripts\python.exe run.py
```

Данные создаются в `local-app/data/`. Не коммитьте эту папку. Дополнительные настройки и ограничения — в [local-app/README.md](local-app/README.md).

## Запуск веб-демонстрации

Из корня репозитория:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory web-demo
```

Откройте http://127.0.0.1:8765. Запуск через двойной щелчок по HTML не поддерживается: нужны HTTP и возможности безопасного контекста браузера.

## Проверки

Из `local-app/`, после установки зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe evaluate.py
```

При подготовке репозитория 17 ноября 2026 года прошли 22 Python-теста. На предыдущем прогоне 34 контрольных примеров demo: precision 1.0, recall 0.9167; три примера не пройдены. Это оценка формализованных правил, а не LLM. Сохранённый отчёт: [local-app/reports/demo-report.md](local-app/reports/demo-report.md).

Веб-демонстрация проверена в Chrome: пять замечаний учебного примера, редактирование, принятие/отклонение, DOCX, сброс подтверждения, история после перезагрузки, изоляция браузерных данных и адаптивность. Выгруженный DOCX открыт через python-docx.
